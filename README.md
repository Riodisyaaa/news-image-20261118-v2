# Wednesday 18 November 2026 — The World in One Day

A dense newspaper front page summing up 18 November 2026's world news in one image — 45 stories, 6 continents — built by an AI agent for make.fun's "Sum up 18 November's world news in one image" bounty, $250 in USDC.

## How to run

```bash
python3 draw_v2.py   # renders entry.png (1024x1024)
node main.ts         # copies entry.png to /output/entry.png
```

The image is drawn deterministically with Python PIL — no network, all artwork original.
